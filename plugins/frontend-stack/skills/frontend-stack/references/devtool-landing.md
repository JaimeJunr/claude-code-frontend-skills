# Developer-tool, API and AI-gateway landings

Read during Direction and Build for these marketing surfaces. With no brand,
run `identity-flow.md` first. These are product patterns, not a visual preset.

## Reference patterns

Derived from these official product pages, inspected on 2026-10-12. Recheck
them during reference research; reuse the lesson, never their text or signature.

| Reference | Pattern to learn from |
|---|---|
| [OpenRouter](https://openrouter.ai/) | Make model discovery and provider choice a product surface; connect catalog, pricing and API-key setup. |
| [Vercel AI Gateway](https://vercel.com/ai-gateway) | Show integration code with SDK/language choices, model pricing and an agent-ready setup action. |
| [Cloudflare AI Gateway](https://www.cloudflare.com/products/ai-gateway/) | Explain routing, caching and request visibility through concrete configuration and product controls. |
| [Amazon Bedrock](https://aws.amazon.com/bedrock/) | Organize model choice, customization and safeguards by the developer's task, with deeper capability links. |
| [Stripe](https://stripe.com/gb) | Show product workflows and integration paths; pair claims with named customer stories and developer docs. |
| [Resend](https://resend.com/) | Make the first API operation tangible with language-specific code, responses and testable product behavior. |

## Build around proof

- **Hero:** state what the product does, for whom and the concrete action to
  start. Show real code or real product UI at readable scale. Add tabs per
  supported SDK/language; verify imports, endpoints, parameters and responses
  against this product's docs. Do not promise unsupported SDKs.
- **Catalog:** when models/providers are the product, expose their real names,
  capabilities, filters and links. Distinguish a provider integration from a
  customer endorsement. If the catalog is not ready, say so.
- **Numbers:** publish only sourced, current figures with units and scope, or
  use none. Label illustrative request data synthetic; it proves a workflow,
  not throughput, uptime, savings or adoption.
- **Pricing:** show the real billing unit, included usage, limits, markup and
  extra fees. Link full pricing. If terms are undecided, say so instead of
  inventing tiers or a free allowance.
- **Docs:** keep quickstart/API docs one click away from the hero and nav.
  Make the path from account or API key to first successful request visible.
- **Agent setup:** offer copyable quickstart code and a copy-for-agent action
  containing actual install steps, environment variable names and docs links.
  Copy placeholders, never live credentials; confirm the action works.
- **Trust:** use only real customer logos with permission and evidence. Use
  product behavior, changelog, status or explicit limitations when social
  proof does not exist. Name only controls the product actually provides.

## Never

- Fake screenshot divs or decorative dashboards posing as shipped product UI.
- Invented metrics, customers, testimonials, badges, prices or capabilities.
- Three identical benefit cards with interchangeable headings.
- Sparkles icons or a purple gradient as shorthand for AI. Explicit user or
  brand commitments still win; do not add these as defaults.
- "Unified", "intelligent" or "seamless" filler. Name the operation and the
  developer's result in the brand's own voice.
